# DSH Terminal

给 DeepSeek Harness 做一层 Claude Code 风格的终端外观，保留 DSH 原生聊天和编辑器。针对 **DSH Desktop 0.12.1 / DSH 0.2.1-rc.2**；部分界面选择器来自该版本，升级后需要重新验证，不建议强制绕过版本约束。

## 安装和关闭

1. 在 DSH 左侧打开 **插件 → 添加插件 → 安装第三方插件**。
2. 输入 `dsh-terminal-theme-0.2.3.tgz` 下载到本机后的**绝对路径**，然后点 **立即启用**。若从旧版升级且界面仍显示旧样式，用桌面应用菜单真正退出 DSH Desktop，再重新打开；仅刷新浏览器或关闭会隐藏到托盘的窗口，不会清除宿主已缓存的旧插件入口。
3. 想要暖炭黑配色，在 **设置 → 通用 → 外观** 选 **深色**。插件跟随原有深色／浅色切换，不会改写外观偏好。
4. 想恢复原样，在插件页停用 `dsh-terminal-theme`。它的样式和颜色层会一并卸载，不需要回滚聊天或配置。

## 外观和边界

- 聊天用左对齐的 `❯` / `●`、方形控件和单线分隔。输入区、待办、待发队列和目标栏保持透明，正文滚动视口本身在整个底部区域的上沿结束。继续使用 DSH 原来的滚动容器和控制器，不依赖滚动事件来追补裁切。极矮布局与专用编辑器浮层保留 DSH 原生布局和安全背景。工作区侧栏仍可收起；命令、附件和权限控件仍是原组件。
- 主对话默认使用可用列宽的 78%（原为 64%），宽屏上限从 920px 提到 1140px；正文与底栏一起加宽，保留窄栏约束和原生手动宽度。
- 一级「过程摘要」保留原有展开／收起。打开后整组操作跟着聊天正文滚动，不再套一个限高滚动框。单次工具的参数、输出、diff 等次级详情保持原交互。
- 正文、编辑区、代码和会话导航采用等宽字体栈。Windows 优先 Cascadia Mono / Consolas；简中优先可用的 Sarasa Mono SC（更纱黑体）或 Noto Sans Mono CJK SC，否则落到系统 CJK 字体。插件不联网下载字体。想要更稳定的中英字符网格对齐，建议安装更纱黑体 Mono SC。
- 显式标语言的代码块优先沿用 DSH 的 Shiki（TextMate）分词。关键词、字符串、数字、函数、注释、diff 增删使用和 VS Code 接近的、差异明显的语法色。未分词且代码结构明确的常见语言，由内置 Highlight.js 补充分词；不能判断的块不染色。DSH 可能把未标记和显式纯文本统一显示成「代码」；这种情况下只能根据内容保守判断。原有复制、换行和原文不变。
- KaTeX 仍负责公式字体和排版，MathML 仍保留。长块公式在自己的区域横向滚动。没有替换 Markdown、代码或公式组件，也不改变 DSH 原有流式公式渲染时机。

## 从源码构建

```powershell
npm run build
npm test
npm pack --ignore-scripts
```

构建不联网、不执行安装脚本。语法补充使用随源码固定的 Highlight.js 11.11.1（BSD-3-Clause），发行包保留上游许可证。代码仅在本机浏览器解析，不发送到外部，也不修改消息或文件。

## 手动回归

启用后打开有真实会话历史的聊天页，在深、浅两种外观检查：

- 中文输入法候选期间不误发，正常提交多行输入；附件、斜杠命令、工具展开、停止和审批入口仍可用。
- 让助手回复一段中英混排文字，包含行内公式 `$E=mc^2$`、宽矩阵的 `$$...$$` 块和一段带语言标记的 JavaScript。窄窗口下整页不能被长公式撑宽；代码进视口后语法颜色可分辨，复制仍给出原始代码。
- 停用插件后，原始气泡、字号设置和配色恢复。
